# Competitive-Market-Analysis-Power-BI-Dashboard
Built an interactive Power BI dashboard for sales and competitor analysis using data integration, transformation, modeling, DAX, and visualization. Delivered business insights to support executive decision making through historical sales performance analysis.

Developed an end to end interactive Power BI sales analysis dashboard based on a business case study for Sintec executives to analyze historical sales performance against key market competitors.

The project covered the complete BI workflow, including:

• Data Integration and Transformation – cleaned, merged, and prepared datasets for analysis
• Data Modeling – built relationships and optimized the data model for reporting
• Exploratory Data Analysis (EDA) – identified sales trends, performance patterns, and competitive insights
• DAX Calculations – created custom measures and KPIs for advanced business analysis
• Interactive Visualization – designed executive friendly dashboards for dynamic exploration and decision making

The final report enables stakeholders to compare company sales performance with competitors, uncover actionable insights, and support more informed business decisions through data driven analysis.

Tools Used: Power BI, Power Query, DAX, Data Modeling, Data Visualization
